# 并行分组协议（Agent Teams 用）

本文件是并行工作的**唯一分工协议**。主人在用 Agent Teams，因此写范围必须互不重叠。

工程结构：单一 Next.js 应用 + `src/`（主人已确认，不采用 monorepo）。
所以路径为 `src/server/modules/...`、`src/app/...`（即 API 路由与页面同处 `src/app`）。

## 1. 分组与写作范围

| 组 | 负责范围（可写目录／文件，其他一律不碰） |
|---|---|
| **GF 基础** | `src/packages/common/**`、`src/server/platform/**`、`migrations/**`、`tests/support/**`、`tests/constraints.test.ts` |
| **GI 身份与目录** | `src/server/modules/identity/**`、`src/server/modules/catalog/**`、`src/server/adapters/**`、`tests/identity.test.ts`、`tests/catalog.test.ts` |
| **GC 内容** | `src/server/modules/reviews/**`、`src/server/modules/content/**`、`src/server/modules/comments/**`、`tests/drafts.test.ts`、`tests/comments.test.ts` |
| **GT 审核与任务** | `src/server/modules/moderation/**`、`src/server/modules/tasks/**`、`src/server/modules/operations/**`、`src/worker/**`、`tests/tasks.test.ts` |
| **GL 接口与页面** | `src/app/**`、`tests/api.test.ts` |
| **GX 流程（主控）** | `src/server/workflows/**`、`docs/**`、`README-切片说明.md` |

## 2. 冻结契约（先合并，之后只增不改）

`GF` 的 `src/packages/common/**`、`src/server/platform/**` 与 `migrations/**` 一旦合并即冻结：

- 别人只读，不改写；
- 业务模块只能通过平台层拿到连接与事务，**不得自己写 SQL 建表或改表**；
- 发现契约缺字段，向主控报告，由主控统一改，不允许就地打补丁。

## 3. 接口约定

```ts
import { withTransaction, withRead } from '@/server/platform/db';   // 唯一连接入口
import { err, DomainError } from '@/packages/common/errors';        // 统一错误
import { ok, buildPage, PaginationDefaults } from '@/packages/common/result';
```

- 每个业务模块**只导出服务对象**，不导出仓储与表定义；
- 服务方法接收 `RequestContext`（`{ userId, role, accountStatus } | null` 形式的调用上下文），
  不要从模块里直接读 Cookie 或 HTTP 对象；
- 模块内不判断 HTTP 状态码。

## 4. 时间与 ID

- 时间一律用 `nowMs()`（`@/server/platform/time`）取 UTC 毫秒；
- ID 一律用 `newId()`（`@/server/platform/id`）生成 UUIDv7；
- 禁止 `Date.now()` 散落各处，禁止用时间戳当业务序号。

## 5. 纪律

- **只做自己桶里的功能**，不顺手做别的组的事；
- 完成后回报：真实产出路径 + 跑了哪条命令 + 实际输出摘要；
- 不允许恒真断言测试：每个测试要能在实现被破坏时变红（例如把 CHECK 删掉、把事务拆开）；
- 不确定的地方写进完成汇报的「未做／不确定」一节，不要猜，不要用假数据把页面填满。
